# Shell Emulator

## 1. Общее описание

Эмулятор оболочки UNIX-подобной ОС с графическим интерфейсом (GUI) на
Python и tkinter. Практическая работа № 1, вариант 25 (дисциплина
«Конфигурационное управление»).

Состояние проекта: **этап 2 — конфигурация**. Эмулятор принимает
параметры командной строки и умеет выполнять стартовый скрипт. Команды
`ls` и `cd` пока являются заглушками.

Требования: Python 3.9+ с модулем `tkinter` (в Linux:
`sudo apt install python3-tk`). Сторонние пакеты не нужны.

Структура репозитория:

```
src/shell_emulator/   исходный код
tests/                модульные тесты
examples/vfs/         примеры директорий-VFS (minimal, files, deep)
examples/startup/     примеры стартовых скриптов эмулятора
scripts/              скрипты ОС (.sh и .bat) для проверки параметров
run.sh, run.bat       запуск эмулятора
```

## 2. Описание функций и настроек

### Параметры командной строки

| Параметр | Описание |
|----------|----------|
| `--vfs-path PATH` | путь к физическому расположению VFS (директория); её имя показывается в заголовке окна и в приглашении |
| `--script PATH` | путь к стартовому скрипту с командами эмулятора |
| `-h`, `--help` | справка |

Оба параметра необязательны и могут идти в любом порядке. При запуске
все заданные параметры выводятся отладочными строками `[debug]` — и в
окно эмулятора, и в консоль. Неизвестный параметр или параметр без
значения — ошибка, код возврата 2.

### Стартовый скрипт

Текстовый файл (UTF-8), одна команда эмулятора на строку.

- Команды выполняются последовательно, пустые строки игнорируются.
- На экране отображается и ввод (приглашение + команда), и вывод, как
  при диалоге с пользователем.
- Ошибочные строки (неизвестная команда, синтаксическая ошибка,
  неверные аргументы) пропускаются: ошибка выводится красным, а
  выполнение продолжается со следующей строки.
- `exit` в скрипте закрывает эмулятор, остальные строки не
  выполняются. Если `exit` нет, после скрипта окно остаётся открытым для
  интерактивной работы.
- Если файл скрипта не найден или не читается, об этом выводится
  сообщение `script: cannot read ...`, эмулятор продолжает работу.

### Окно

- Заголовок окна содержит имя VFS: `Shell Emulator - VFS: <имя>`.
- Сверху — журнал диалога, снизу — приглашение и строка ввода.
- Клавиши `Up` / `Down` перебирают историю введённых команд.

### Парсер

Ввод делится на команду и аргументы по пробелам (`parser.parse_line`):

- пробельные символы разделяют слова;
- `"..."` — аргумент с пробелами, внутри допустимы `\"` и `\\`;
- `'...'` — содержимое берётся буквально;
- `\` вне кавычек экранирует следующий символ;
- `""` — пустой аргумент.

### Команды

| Команда | Описание |
|---------|----------|
| `ls [арг...]` | заглушка: печатает своё имя и аргументы |
| `cd [арг...]` | заглушка: печатает своё имя и аргументы |
| `exit` | закрывает эмулятор |

### Ошибки

- `shell: <cmd>: command not found` — неизвестная команда;
- `shell: syntax error: ...` — незакрытая кавычка или `\` в конце строки;
- `exit: too many arguments` — у `exit` не должно быть аргументов.

## 3. Сборка и тесты

Сборка не требуется. Запуск:

```
./run.sh [параметры]          # Linux / macOS
run.bat [параметры]           # Windows
```

Скрипты ОС для проверки параметров (каждый запускает эмулятор с
разными сочетаниями параметров; окно закрывается командой `exit` в
стартовом скрипте):

```
scripts/stage2_basic.sh       scripts\stage2_basic.bat
scripts/stage2_errors.sh      scripts\stage2_errors.bat
```

Тесты (из корня репозитория):

```
python3 -m unittest
```

GUI-тесты автоматически пропускаются, если нет дисплея или `tkinter`
(в Linux без дисплея: `xvfb-run -a python3 -m unittest`).

## 4. Примеры использования

Запуск со стартовым скриптом и VFS:

```
./run.sh --vfs-path examples/vfs/deep --script examples/startup/with_errors.txt
```

```
[debug] emulator started with parameters:
[debug]   --vfs-path = examples/vfs/deep
[debug]   --script   = examples/startup/with_errors.txt
[debug]   VFS name   = deep
deep:/$ ls
ls: args = []
deep:/$ unknown_command arg
shell: unknown_command: command not found
deep:/$ ls after_error
ls: args = ['after_error']
```

Интерактивный диалог:

```
default:/$ ls
ls: args = []
default:/$ cd "My Documents" /tmp
cd: args = ['My Documents', '/tmp']
default:/$ ls 'a  b' "c\"d"
ls: args = ['a  b', 'c"d']
default:/$ pwd
shell: pwd: command not found
default:/$ ls "abc
shell: syntax error: unterminated quote: "
default:/$ exit
```
