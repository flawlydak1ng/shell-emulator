# Shell Emulator

## 1. Общее описание

Эмулятор оболочки UNIX-подобной ОС с графическим интерфейсом (GUI) на
Python и tkinter. Практическая работа № 1, вариант 25 (дисциплина
«Конфигурационное управление»).

Состояние проекта: **этап 1 — REPL**. Диалог с пользователем уже
работает, команды `ls` и `cd` пока являются заглушками.

Требования: Python 3.9+ с модулем `tkinter` (в Linux:
`sudo apt install python3-tk`). Сторонние пакеты не нужны.

Структура репозитория:

```
src/shell_emulator/   исходный код
tests/                модульные тесты
run.sh, run.bat       запуск эмулятора
```

## 2. Описание функций и настроек

### Окно

- Заголовок окна содержит имя VFS: `Shell Emulator - VFS: <имя>`.
- Сверху — журнал диалога, снизу — приглашение и строка ввода.
- Клавиши `Up` / `Down` перебирают историю введённых команд.

### Парсер

Ввод делится на команду и аргументы по пробелам (`parser.parse_line`):

- пробельные символы разделяют слова;
- `"..."` — аргумент с пробелами, внутри допустимы `\"` и `\\`;
- `'...'` — содержимое берётся буквально;
- `\` вне кавычек экранирует следующий символ;
- `""` — пустой аргумент.

### Команды

| Команда | Описание |
|---------|----------|
| `ls [арг...]` | заглушка: печатает своё имя и аргументы |
| `cd [арг...]` | заглушка: печатает своё имя и аргументы |
| `exit` | закрывает эмулятор |

### Ошибки

- `shell: <cmd>: command not found` — неизвестная команда;
- `shell: syntax error: ...` — незакрытая кавычка или `\` в конце строки;
- `exit: too many arguments` — у `exit` не должно быть аргументов.

## 3. Сборка и тесты

Сборка не требуется. Запуск:

```
./run.sh          # Linux / macOS
run.bat           # Windows
```

Тесты (из корня репозитория):

```
python3 -m unittest
```

GUI-тесты автоматически пропускаются, если нет дисплея или `tkinter`
(в Linux без дисплея: `xvfb-run -a python3 -m unittest`).

## 4. Примеры использования

```
default:/$ ls
ls: args = []
default:/$ cd "My Documents" /tmp
cd: args = ['My Documents', '/tmp']
default:/$ ls 'a  b' "c\"d"
ls: args = ['a  b', 'c"d']
default:/$ pwd
shell: pwd: command not found
default:/$ ls "abc
shell: syntax error: unterminated quote: "
default:/$ exit
```
